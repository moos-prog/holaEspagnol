# Hola! — application iPhone gratuite

## Ce que contient cette version
- Application web installable (PWA), sans abonnement.
- Leçons, quiz, points XP et progression sauvegardée localement.
- Tuteur pédagogique à réponses guidées.
- Synthèse vocale espagnole via le navigateur.
- Reconnaissance vocale si le navigateur iOS la prend en charge.
- Mise en cache pour réutilisation après le premier chargement.

## Important
Cette version n'utilise pas de service d'IA générative distant. Le tuteur propose des réponses pédagogiques intégrées pour rester gratuit et éviter une clé API payante. Les fonctions vocales dépendent des capacités et autorisations du navigateur.

## Publication gratuite avec GitHub Pages
1. Crée un compte sur https://github.com si nécessaire.
2. Crée un dépôt public nommé `hola-espagnol`.
3. Décompresse le ZIP et téléverse tous les fichiers du dossier dans le dépôt (index.html à la racine).
4. Dans le dépôt : Settings → Pages.
5. Dans « Build and deployment », choisis « Deploy from a branch », branche `main`, dossier `/ (root)`, puis Save.
6. Attends quelques minutes : GitHub affichera une adresse HTTPS du type `https://TON-PSEUDO.github.io/hola-espagnol/`.

## Installation sur iPhone
1. Ouvre l'adresse HTTPS publiée dans Safari (pas dans un navigateur intégré).
2. Appuie sur Partager (carré avec flèche vers le haut).
3. Choisis « Sur l'écran d'accueil » / « Ajouter à l'écran d'accueil ».
4. Si l'option est proposée, active « Ouvrir comme app web », puis Ajouter.

Les intitulés peuvent varier selon la version d'iOS. L'installation PWA est gratuite. La publication sur l'App Store est un processus différent et n'est pas incluse.
